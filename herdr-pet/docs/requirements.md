# herdr-pet 需求

更新日期：2026-09-19

## 当前范围

### 状态

- 连接当前 Herdr JSON API，支持默认 session、`HERDR_SESSION` 和 `HERDR_SOCKET_PATH`。
- 优先展示当前聚焦 agent；没有聚焦项时按 blocked、working、done、idle、unknown 的优先级选择。
- agent 状态映射为睡眠、工作、需要注意、完成庆祝、中性和离线动画。
- 悬停气泡展示 agent 名称、状态、终端标题和工作目录。

### 窗口与交互

- 使用透明、无边框、不可缩放的独立窗口。
- 左键拖拽必须使用系统原生窗口拖拽，连续拖拽不能漂移、抖动或阻塞 UI。
- 右键菜单提供：
  - 皮肤选择；当前仅有“经典像素”。
  - 退出程序。
- 气泡优先出现在宠物上方；上方空间不足时出现在下方。
- 气泡尺寸跟随内容，并受窗口可用区域约束；过长内容允许滚动。
- 气泡必须具有圆角、边框、阴影和指向宠物的尾巴，且不能拦截拖拽。

### 全屏悬浮

- 普通桌面环境保持在其他应用窗口前。
- Tauri 在窗口构建阶段启用 `always_on_top` 和 `visible_on_all_workspaces`。
- macOS 在窗口首次显示前使用 `Accessory` 激活策略，并设置 `NSScreenSaverWindowLevel`、`CanJoinAllSpaces` 和 `FullScreenAuxiliary`。
- 锁屏、安全桌面和 DRM 保护内容不属于可覆盖范围。

### 性能与响应

- UI 主线程不得执行网络、socket、进程查询或文件 I/O。
- Herdr API reconcile 和订阅读取必须在 Rust 后台线程执行，不得进入 WebView。
- Rust 后端只向 WebView 发送纯数据状态快照。
- 拖拽不得为每一帧建立 IPC 往返。
- 右键菜单、点击和悬停反馈必须由输入事件即时触发；后台状态刷新不得阻塞交互。
- 默认空闲绘制频率不高于动画所需的 2.5 FPS，输入事件可按需触发额外重绘。

## 验收清单

- 启动 Herdr 和 `herdr-pet` 后，宠物状态与所选 agent 一致。
- 连续拖拽 30 秒，窗口保持跟手，释放后不继续移动，菜单和 hover 仍可使用。
- 右键可打开菜单、选择当前皮肤并退出。
- 将另一个应用切换到 macOS 原生全屏后，宠物仍显示在其前方。
- 将鼠标移到宠物上，气泡不会超出窗口；上方无法容纳时自动转到下方。
- Herdr 停止或 socket 断开时，宠物显示离线且 UI 保持可交互。
- `npm test` 通过。

## 后续功能候选

### 优先级高

- 完成/阻塞提醒：状态变为 done 或 blocked 时播放可关闭的轻提示，并支持勿扰时段。
- agent 快捷操作：双击聚焦对应 Herdr pane；菜单中提供发送提示、复制工作目录和打开 workspace。
- session 选择器：在多个本地 Herdr session 之间切换，并显示当前连接目标。
- 位置与设置持久化：保存窗口位置、皮肤、提醒和动画偏好，多显示器变化后自动校正。
- 开机启动与托盘入口：支持隐藏/显示、重置位置和退出。

### 表现与互动

- 更多皮肤：不同角色、配色、像素密度和高对比度主题。
- 状态专属动画：输入、思考、等待授权、失败、完成和长时间空闲动作。
- 点击互动：单击回应、双击动作、拖拽速度影响表情，但不得牺牲拖拽流畅度。
- 临时事件：agent 完成时庆祝、阻塞时求助、离线后尝试重新连接。
- 可选音效，并提供独立音量、静音和系统勿扰联动。

### 可用性

- 多语言界面和状态文案。
- 减少动态效果、动画关闭、高对比度和键盘可访问菜单。
- 多显示器边界约束、屏幕缩放变化处理和“重置到可见区域”。
- 隐私模式：气泡隐藏工作目录和终端标题。

### 工程质量

- 为状态切换、菜单动作、气泡布局和 session 选择增加确定性测试。
- 增加空闲 CPU、状态更新和连续拖拽的手动性能基线。
- 打包 macOS/Windows 应用，提供图标、签名、自动更新和崩溃日志开关。
